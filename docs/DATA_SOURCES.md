## Rules for adding new sources

- If you pull data from a public website or repository, add a row here **before** you commit the data.
- Check the source's licence explicitly — "public" does not mean "commercially licensed."
- Never include: client data, data containing real personal information, or data from social media.
- If in doubt, generate synthetic data instead and note it as self-authored here.
