Executive Summary

This is a partial-fix state audit. Since the previous run, six bugs were corrected directly in source: the email regex, list mutation in process_records, the ZeroDivisionError guard, MD5 → SHA-256, timezone-naive timestamp, and merge_dicts None guard are all fixed and confirmed. Three open bugs remain that will crash the pipeline on first real use.

The most dangerous is the enrich_record → None propagation: any API failure — a timeout, a 4xx, a DNS error — silently injects None into the pipeline. The subsequent transform_record(None) raises AttributeError, aborts the entire run, and leaves no output file written. The two file-handle leaks (load_records, save_results) are a resource-exhaustion risk under load and a potential silent data-loss risk on the write side.

The Refactorer identified 8 additional improvements — none conflicting with the open bugs — including hardening get_results_summary against a latent KeyError, making both enrich_record and transform_record pure (non-mutating), and compiling the email regex once at module level. Fix bugs first, then apply refactorings in the order given.

✅ Fixes confirmed in this audit (not re-reported as open issues) validate_email regex tightened · process_records uses list comprehension (no mutation) · calculate_average guards empty list · generate_id uses SHA-256 · format_timestamp timezone-aware · merge_dicts None-safe

📝 Documenter — Public API Reference

Module Overviews

app.py

The core pipeline module. Loads JSON records from disk, filters by email validity, optionally enriches each record via an external HTTP API, applies business-logic transformations (name normalisation, average-score calculation), persists the results to a JSON output file, and returns a summary dict. Depends on stdlib (json, re) and requests. Contains two resource-management bugs (unclosed file handles) and one pipeline crash condition (silent None return from enrichment).

utils.py

Six stateless helper functions for ID generation, timestamp formatting, dict merging, list chunking, list flattening, and safe nested dict traversal. Relies only on stdlib (hashlib, datetime). None of the six functions are imported or called by app.py — they are standalone extension points. One function (flatten) has an undocumented depth limitation; another (format_timestamp) performs no input validation.

API Reference — app.py

load_records(filepath: str) → list[dict]
Opens filepath, deserialises it as JSON, and returns the list of record dicts. No schema validation.
⚠ LEAK — file handle opened with bare open(), never closed.
validate_email(email: str) → bool
Returns True if email matches [^@\s]+@[^@\s]+ — at least one non-whitespace, non-@ character on each side of a single @.
ℹ No docstring. Regex is minimal — many technically invalid addresses will pass.
process_records(records: list[dict]) → list[dict]
Returns a new list containing only records whose "email" passes validate_email. Does not mutate the input. Records missing "email" are excluded (defaulted to "").
enrich_record(record: dict, api_url: str) → dict | None
Sends GET {api_url}/enrich?id={record["id"]} (5 s timeout). On success, sets record["enriched"] to the parsed response and returns the mutated record. Returns None on any exception.
⚠ BREAKS — swallows all exceptions silently; None propagates into run_pipeline and crashes transform_record. Also mutates record in-place as a side effect.
calculate_average(values: list[float | int]) → float
Returns the arithmetic mean of values. Returns 0.0 for an empty list.
ℹ No docstring. No type enforcement — non-numeric elements raise TypeError.
transform_record(record: dict) → dict
Strips and title-cases record["name"]; sets record["score"] to the mean of record["scores"]. Mutates and returns the same dict.
⚠ BREAKS — raises AttributeError/TypeError if record is None (see run_pipeline bug).
save_results(records: list[dict], output_path: str) → None
Serialises records to indented JSON and writes to output_path.
⚠ LEAK — file handle opened with bare open(), never closed. Write buffer may not flush.
get_results_summary(records: list[dict]) → dict
Returns {"total": int, "avg_score": float}. Expects all records to have a "score" key.
⚠ WARNS — hard access r["score"] raises KeyError if records have not passed through transform_record.
run_pipeline(input_path: str, output_path: str, enrich_api_url: str) → dict
Orchestrates: load → filter → enrich → transform → save → summarise. Returns the summary dict.
⚠ No docstring. Inherits both file-handle leaks. None values from failed enrichments crash the pipeline (see BUG-1).

API Reference — utils.py

generate_id(record: dict) → str
Returns a 64-char lowercase hex SHA-256 digest of the UTF-8-encoded record["email"] (defaults to ""). Deterministic; collision-resistant.
ℹ Two records sharing an email receive the same ID. Missing email always produces the same fixed digest.
format_timestamp(ts: float | int | str) → str
Returns an ISO 8601 UTC string (timezone-aware) for Unix timestamp ts. Coerces via float(ts).
⚠ No input validation — non-numeric strings raise ValueError; None raises TypeError. Documented in docstring.
merge_dicts(*dicts: dict | None) → dict
Merges dicts left-to-right; later keys overwrite. Skips None arguments. Returns a new dict.
chunk_list(lst: list, size: int) → list[list]
Splits lst into consecutive sublists of at most size elements. Last chunk may be shorter.
ℹ size <= 0 raises ValueError from range(); no explicit guard or error message.
flatten(nested_list: list[list]) → list
Flattens a one-level nested list into a single list via list comprehension.
⚠ One-level only. Deeper nesting produces silently wrong output. Depth limit not in the docstring.
safe_get(d: dict, *keys, default=None) → Any
Traverses a nested dict along keys, returning default if any key is missing or if a non-dict is encountered mid-path.
⚠ When default is a non-None non-dict value, it may be propagated as current and traversed on subsequent keys, returning a silently wrong value (see BUG-4).

6 · Gotchas

🔴
Any API failure crashes the entire run. enrich_record() returns None on any exception. That None reaches transform_record and raises AttributeError. The output file is never written. Fix BUG-1 before running against a real API.
🔴
File handles are never closed. Both load_records() and save_results() use bare open(). Under repeated calls (e.g. a server loop), file descriptors accumulate. The write buffer on save may not flush on crash.
🟡
utils.py is entirely disconnected from app.py. None of its six functions are imported. Don't expect them to run in the pipeline unless you add the imports explicitly.
🟡
Empty scores produce score: 0.0 — not distinguishable from a real zero. Record 004 has "scores": []; it survives filtering and outputs "score": 0.0. Callers cannot tell "no data" from "scored zero".
🟡
Filtered records vanish silently. Records 003 and 005 are dropped by process_records() with no log message. If you add 10 records and get 7 in the output, the only way to find the missing three is to compare input and output manually.
